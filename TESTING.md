# PdfReader v0.1.0 — Testing

## Cache-vrije testlink

https://gasvdv-lab.github.io/PdfReader/?v=0.1.0

## Android

1. Controleer dat `v0.1.0` zichtbaar is.
2. Controleer dat PDF.js een groen vinkje/versie toont.
3. Tik `PDF openen`.
4. Kies een PDF met meerdere pagina's.
5. Controleer:
   - bestandsnaam verschijnt;
   - totaal aantal pagina's klopt;
   - renderstatus wordt `✓ Pagina 1 gerenderd`;
   - pagina 1 is zichtbaar;
   - geen pagina 2 wordt gerenderd.

## Windows

Herhaal dezelfde test in Chrome of Edge.

## Acceptatiecriterium

v0.1.0 is geslaagd wanneer dezelfde lokale PDF op Android én Windows geopend kan worden en pagina 1 correct zichtbaar is.

Pas daarna doorgaan naar v0.1.1 — Page Navigation.
