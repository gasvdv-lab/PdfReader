# pdfReader Roadmap

## Productvisie

pdfReader moet meer zijn dan een klassieke PDF-viewer.

De uiteindelijke productpijlers zijn:

1. Lezen
2. Bewerken
3. Begrijpen
4. Vergelijken
5. Meten

## v0.1.0 — Reader Foundation

Status: eerste release

- PWA/webapp
- Android + Windows
- PDF lokaal openen
- renderen
- pagina navigatie
- zoom
- passend op breedte
- GitHub Pages

## v0.2.0 — Complete Reader

Gepland:

- continue scroll
- thumbnails
- tekst zoeken
- tekst selecteren
- fit page / fit width
- recente bestanden
- keyboard- en touchverbeteringen
- lokaal gebundelde PDF-engine

## v0.3.0 — Annotaties

Gepland:

- highlight
- vrije pen
- tekstvak
- notitie
- lijn
- rechthoek
- cirkel
- verwijderen
- undo/redo

## v0.4.0 — Pagina-editor

Gepland:

- pagina draaien
- pagina verwijderen
- pagina dupliceren
- pagina herschikken
- lege pagina toevoegen
- PDF samenvoegen
- pagina's extraheren

## v0.5.0 — Export Engine

Gepland:

- bewerkte PDF genereren
- opslaan als nieuwe PDF
- annotaties in export verwerken

## v0.6.0 — Document Inspector

Gepland:

- tabellen detecteren
- datums herkennen
- bedragen herkennen
- deadlines/referenties herkennen
- revisies signaleren
- gestructureerde documentinformatie

## v0.7.0 — Compare Mode

Gepland:

- twee PDF-versies openen
- visuele vergelijking
- toevoegingen/verwijderingen/wijzigingen markeren

## v0.8.0 — Plan Mode

Gepland:

- schaal kalibreren
- afstand meten
- oppervlakte meten
- hoeken meten
- meetresultaten beheren
