# PdfReader v0.3.0 — Annotation Foundation

## Doel
De technische basis leggen voor markeren, tekst toevoegen, tekenen, notities en vormen.

## Nieuw
- aparte annotatielaag boven canvas + text layer
- annotaties per pagina in geheugen
- genormaliseerde coördinaten zodat posities behouden blijven bij zoom/resize/fullscreen
- unieke annotatie-ID's en selectie
- annotatiemodus via menu en fullscreenmenu
- testannotatie: tik op pagina om een foundation point te plaatsen
- nieuwe PDF reset annotaties
- continuous scroll schakelt annotatiemodus uit

## Nog niet
- highlight
- tekst typen
- pen
- notities
- vormen
- permanente opslag/export
- undo/redo

## Volgende stap
v0.3.1 — Highlight / Markeren
