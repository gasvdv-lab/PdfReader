# PdfReader v0.3.1.2 — Highlight Action Bar UX Fix

## Probleem
Op Android stond de Markeren-actiebalk onderaan het scherm. Daar verschijnen ook Android tekstselectie, Google zoekkaart en de systeemnavigatie.

## Fix
- highlight-actiebalk staat nu bovenaan de PDF-viewer
- sticky onder de readercontrols
- in fullscreen compact bovenaan
- op mobiel compacter
- geen conflict meer met de onderste Android selectie-/systeeminterface
